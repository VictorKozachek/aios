# Сплэш AIOS · SkyNet — спецификация (v1 «Void»)

**Статус:** вариант выбран владельцем 2026-11-09, реализуется в T7.
**Мокапы:** [`variants/v1.png`](variants/v1.png) (1280×800), [`variants/v1-800x600.png`](variants/v1-800x600.png).
**Альтернативы (для истории):** [`variants/v2.png`](variants/v2.png) — терминальный минимализм,
[`variants/v3.png`](variants/v3.png) — премиальный тёплый тёмный.

Документ описывает экран, который ядро рисует на framebuffer **без декодера PNG,
без шрифтового рендерера, без GPU и без анимации**: построчный градиент,
1-пиксельные линии и три предрендеренных битмапа (марка, wordmark, атлас глифов),
которые блендятся целочисленным lerp.

Все числа ниже сняты с эталонного рендера [`tools/design/splash_render.py`](../../tools/design/splash_render.py)
и совпадают с мокапом пиксель в пиксель.

---

## 1. Замысел

- Глубокий тёмно-синий градиент, один холодный акцент (#86A9FF), много воздуха.
- Марка — «апертура/глаз»: разомкнутое кольцо с точкой-зрачком. Тот же мотив
  повторяется в wallpaper меню Limine, только крупно, поэтому загрузка читается
  как одна история: меню → глаз, сплэш → его марка.
- Контент стоит в центре по горизонтали, оптический центр блока — 42.5 % высоты,
  чтобы под ним осталось место для растущего лога.
- Всё, что видно на экране, — либо градиент, либо прямоугольник 1×N, либо
  битмап с 8-битной альфой. Никаких скруглений, теней, блюра и векторной графики
  в рантайме.

Тон: **спокойный, технический, дорогой**. Не пиксель-арт, не «гейм-стиль»,
не macOS-подражание.

**Альтернативы, которые не выбраны** (оставлены в `variants/`, в сборку не
идут):

- **v2 «Terminal»** — выравнивание влево, всё моноширинное, вертикальная
  линейка-рейка, зелёный `[ ok ]`. Настроение: инженерный терминал.
- **v3 «Champagne»** — тёплый угольный градиент, шампань-акцент, разреженный
  Inter Light, статусы как spec-sheet с волосяными линиями между строками.
  Настроение: премиальный тёмный.

Выбран **v1**: он лучше всех читается на 800×600, требует меньше всего
акцента и естественно продолжает мотив «глаза» из меню Limine.

## 3. Фон

Вертикальный градиент сверху вниз, три стопа:

| t | Цвет |
|---|---|
| 0.00 | `#05070C` |
| 0.52 | `#0A1120` |
| 1.00 | `#04060A` |

Формула (на строку `y`, `H` — высота):

```
t     = (y + 0.5) / H                    // 0..1
t < 0.52:  c = lerp(C0, C1, t / 0.52)
иначе:     c = lerp(C1, C2, (t - 0.52) / 0.48)
```

Целые числа: считаем в 8.8 fixed point, чтобы дизеринг имел дробную часть.

```
t256  = ((y * 2 + 1) * 128) / H          // 0..256
c_q   = lerp_q(C0_q, C1_q, t256)         // 8.8 fixed point, 0..65280
out   = (c_q + (BAYER[y & 3][x & 3] << 4)) >> 8
```

`BAYER` — матрица 4×4, значения 0..15:

```
0  8  2 10
12 4 14  6
3 11  1  9
15 7 13  5
```

Дизеринг обязателен: без него на тёмном градиенте видны полосы шириной
40–80 px. С ним шаг квантования размывается в мелкую регулярную рябь,
которая на 8 битах не читается как шум. Никаких других элементов фона нет:
ни виньетки, ни звёзд, ни сетки.

## 4. Сетка и координаты

Система **одного масштаба**: размеры всех элементов (марка 64 px, wordmark
252×65, кегль 15 px) одинаковы на 1280×800 и на 800×600. Меняются только
отступы, потому что блок центрируется по формуле. Это избавляет ядро от
второго набора ассетов и от масштабирования битмапов.

```
cx   = W / 2                 // центр по горизонтали (целое)
left = cx - 240              // левый край колонки 480 px
top  = (H * 42 + 50) / 100 - 179   // верх марки, целочисленно, с округлением
```

Константа 179 подобрана так, что блок «марка → последняя строка статуса»
(≈ 366 px) стоит чуть выше геометрического центра: его середина попадает на
42.5 % высоты, и под ним остаётся место для растущего лога.

## 7. Атлас глифов

**Формат.** `atlas-jbm15.png` — RGBA PNG 144×120 (белые чернила + альфа);
в ядре — alpha-маска 144×120, 1 байт на пиксель, строка за строкой сверху
вниз: `ATLAS_JBM15_ALPHA: &[u8]`.

**Раскладка.**

```
cell_w = 9, cell_h = 20, cols = 16, rows = 6
idx  = ch - 0x20            // ' ' (0x20) -> 0, '~' (0x7E) -> 94
sx   = (idx % 16) * 9
sy   = (idx / 16) * 20
```

Глифы идут построчно: `' ' ! " # $ % & ' ( ) * + , - . /` — первая строка,
`0 1 2 … ?` — вторая, `@ A B … O` — третья, `P … _` — четвёртая,
`` ` a … o `` — пятая, `p … ~` — шестая. Последняя ячейка (idx 95)
не используется.

**Базовая линия** — 15 px от верха ячейки; высота строки 21 px
(5 px запаса снизу). Пробел — пустая ячейка полной ширины 9 px.

**Отрисовка строки:**

```rust
fn draw_text(fb, s: &str, mut x: i32, baseline: i32, color: u32, alpha: u8, tracking: i32) {
    for ch in s.bytes() {
        let ch = if (0x20..=0x7E).contains(&ch) { ch } else { b'?' }; // вне ASCII — '?'
        let idx = (ch - 0x20) as usize;
        let sx = (idx % 16) * 9;
        let sy = (idx / 16) * 20;
        blit_mask(fb, ATLAS_JBM15_ALPHA, 144, 120, sx, sy, 9, 20,
                  x, baseline - 15, color, alpha);
        x += 9 + tracking;
    }
}
```

**Блендинг** (одинаков для масок и RGBA, целочисленный, без float):

```rust
// dst, src — 0x00RRGGBB
fn blend(dst: u32, src: u32, a: u32) -> u32 {
    let ia = 255 - a;
    let r = (((dst >> 16) & 0xff) * ia + ((src >> 16) & 0xff) * a) / 255;
    let g = (((dst >>  8) & 0xff) * ia + ((src >>  8) & 0xff) * a) / 255;
    let b = (( dst        & 0xff) * ia + ( src        & 0xff) * a) / 255;
    (r << 16) | (g << 8) | b
}
```

Полупрозрачные края глифов уже зашиты в альфу — отдельного сглаживания в ядре
не нужно. Значение `alpha < 255` используется только для марки (242); весь
текст (подпись, хеш, статусы, лог) рисуется с альфой 255.

**Чего в атласе нет:** кириллицы, греческого, псевдографики, символа `·`.
Все строки сплэша — чистый ASCII. Если в лог попадёт не-ASCII символ, он
заменяется на `?`, чтобы не сбить шаг сетки.

## 8. Сборка ассетов

```bash
# мокапы + ассеты + wallpaper (нужны Pillow и numpy)
python3 tools/design/splash_render.py

# PNG -> Rust (по одному файлу)
python3 tools/png2rust.py docs/design/assets/logo-aios.png \
    --name logo_aios --out kernel/assets/logo_aios.rs
python3 tools/png2rust.py docs/design/assets/wordmark-aios-v1.png \
    --name wordmark_aios --out kernel/assets/wordmark_aios.rs
python3 tools/png2rust.py docs/design/assets/atlas-jbm15.png \
    --name atlas_jbm15 --out kernel/assets/atlas_jbm15.rs
```

Сгенерированные `.rs` кладутся в `kernel/assets/` (границы задачи T7) и
подключаются как модули: `mod logo_aios;` и т. д. Файлы шрифтов в репозиторий
образа не попадают — только маски.

`png2rust.py` сам определяет, что RGB во всех пикселях одинаковый, и выдаёт
1-байтовую маску (`*_ALPHA`) вместо 4-байтового RGBA (`*_RGBA`); для форса есть
`--mode rgba|mask`. Маска — это те же данные, что RGBA, но без постоянного
RGB: для монохромной марки, wordmark и атласа это в 4 раза меньше байт при
идентичном результате блендинга. Если понадобится полноцветный ассет,
`--mode rgba` даёт классические 4 байта на пиксель (путь проверен на тестовой
RGBA-картинке). Примеры уже сгенерированы в [`generated/`](generated/):

| Файл | Данные в образе | Вес `.rs` |
|---|---|---|
| `logo_aios.rs` | 4 096 B | 14.8 КБ |
| `wordmark_aios.rs` | 16 380 B | 61.4 КБ |
| `atlas_jbm15.rs` | 17 280 B | 64.3 КБ |

Все три компилируются `rustc --edition 2021 --crate-type lib`; вес `.rs` — это
исходный текст, в бинарник идут только массивы.

Проверка актуальности: `python3 tools/png2rust.py <png> --name <n> --out <rs> --check`
(код возврата 2 — файл устарел).

## 9. Порядок отрисовки

Один проход, без очистки в чёрный и без задержек. Всё, что ниже, — после
получения `framebuffer` из `BootInfo`, до первого `hlt`.

```rust
let H = fb.height as i32;
let W = fb.width  as i32;
let cx = W / 2;
let left = cx - 240;
let top = (H * 42 + 50) / 100 - 179;   // 157 при H=800, 73 при H=600

// 1. фон: одна строка градиента за раз (см. §3)
for y in 0..H { fb.fill_row(y, gradient_row(y, H)); }

// 2. марка
blit_mask(&mut fb, LOGO_AIOS_ALPHA, 64, 64, 0, 0, 64, 64,
          cx - 32, top, ACCENT, 242);

// 3. wordmark
blit_mask(&mut fb, WORDMARK_AIOS_ALPHA, 252, 65, 0, 0, 252, 65,
          cx - 126, top + 102, INK, 255);

// 4. подпись и хеш — атласом, по центру
draw_text(&mut fb, "SkyNet v0.0.1", cx - 129 / 2, top + 194, INK_DIM, 255, 1);
draw_text(&mut fb, "git 2214998",   cx - 109 / 2, top + 218, INK_HASH, 255, 1);

// 5. разделитель: 480 x 1, белый @ 9 %
fb.fill_rect(left, top + 240, 480, 1, blend_bg(WHITE, 23));

// 6. четыре строки статуса
for (i, (label, value)) in STATUS.iter().enumerate() {
    let base = top + 282 + 28 * i;
    fb.disc(left + 2, base - 5, 2, ACCENT, 178);        // точка «ok»
    draw_text(&mut fb, label, left + 16, base, INK_DIM, 255, 0);
    draw_text_right(&mut fb, value, left + 480, base, INK, 255, 0);
}

// 7. лог: строки добавляются по мере инициализации
for (i, line) in log.lines().enumerate() {
    let base = top + 410 + 21 * i;
    if base > H - 48 { break; }
    draw_text(&mut fb, line, left, base, INK_FAINT, 255, 0);
}
```

**Ключевые правила:**

1. `left` и `top` считаются один раз из `W`/`H`; всё остальное — смещения.
2. Никаких `sleep`, «минимального времени показа» и анимации: сплэш — это
   первый кадр, а не заставка. Требование T7 — ≤ 100 мс от `framebuffer init`
   до появления картинки и нулевой вклад в время до готовности API.
3. Лог не перерисовывает экран: каждая новая строка — один `draw_text` в
   следующую свободную базовую линию. Когда место кончилось — скролл не нужен,
   строки просто перестают рисоваться (на M0 лог уходит в serial).
4. Значения статусов — динамические, из `BootInfo`; строки-метки — константы
   в `.rodata` (ASCII). Версия и хеш — из `option_env!("AIOS_VERSION")` и
   `option_env!("GIT_HASH")`, fallback — `v0.0.0-unknown`.

## 10. Меню Limine

Wallpaper [`assets/wallpaper.jpg`](assets/wallpaper.jpg): 1920×1080, JPEG q92,
130 700 B (≤ 400 КБ), та же палитра, мотив — тот же «глаз», но крупно:
кольца радиусом 118…1010 px с центром в (1512, 508), зрачок 38 px с бликом,
мягкое свечение. Мотив смещён вправо, поэтому центральная колонка (где Limine
рисует пункты меню) остаётся спокойной: средняя яркость зоны меню (x 700…1220,
y 240…840) — 22.3/255, p99 — 37, максимум — 51. Белому тексту меню хватает
контраста.

Мотив оригинальный: кольца и зрачок нарисованы с нуля
([`tools/design/splash_render.py`](../../tools/design/splash_render.py)), никаких
кадров, HUD или логотипов из фильмов в дистрибутиве нет.

Wallpaper декодируется `stb_image` в RGBA 1920×1080 ≈ **8.3 МБ RAM** на время
меню — это нормально. 4K не предлагать: 3840×2160 ≈ 33 МБ, и на M0 это лишнее.

### 10.1. Конфиг (вписать в `build/limine.conf`)

Ключи сверены с `CONFIG.md` Limine (trunk, 12.9.x); на конкретной версии
12.9.6 их нужно один раз проверить в QEMU и зафиксировать в отчёте T7.

```ini
# --- глобальные опции -----------------------------------------------------
timeout: 3
default_entry: 1

interface_resolution: 1280x800
wallpaper: boot():/wallpaper.jpg
wallpaper_style: stretched

interface_branding: AIOS · SkyNet v0.0.1
interface_branding_colour: E8EEF9
interface_help_colour: 6E7F99
interface_help_colour_bright: 86A9FF
interface_help_hidden: yes

# терминал/меню: полупрозрачная тёмная подложка поверх wallpaper
term_background: 6605080E          # TT RRGGBB: 40 % от #05080E
term_foreground: D7DEE9
term_margin: 64
term_margin_gradient: 4

term_palette:        05070C;C06A6A;7FA98F;A98F6A;86A9FF;A68FD0;7FB8C9;6B7A91
term_palette_bright: 2A3444;E08585;9FD0B0;D9C08A;A8C4FF;C4AEDC;A8D8E6;E8EEF9
```

| Роль | Значение |
|---|---|
| Фон меню | wallpaper + подложка `#05080E` @ 40 % |
| Текст пункта | `#D7DEE9` (`term_foreground`) |
| Выделение | инверсия (Limine рисует `ESC[7m`): плашка `#D7DEE9`, текст `#0B1220` |
| Брендинг | `AIOS · SkyNet v0.0.1`, `#E8EEF9` |
| Хелп/таймер | `#6E7F99`, яркий `#86A9FF` (или скрыт) |

**Про выделение.** Отдельного ключа цвета выделенной строки в Limine 12.x нет:
`common/menu.c` печатает `\e[7m` и снимает `\e[27m`, то есть инвертирует
текущую пару foreground/background. Поэтому плашка получается светлой
(`#D7DEE9`) с тёмным текстом. Если нужна более спокойная синяя плашка —
единственный рычаг — `term_foreground`/`term_background`; например
`term_foreground: C9D4E6` даст плашку `#C9D4E6`. Проверить в QEMU на версии
12.9.6 и зафиксировать в отчёте T7.

**Таймаут.** `timeout: 3` — три секунды: хватает прочитать брендинг, не
раздражает при перезагрузках. Для CI/скриптов — `timeout: 0`, для отладки —
`timeout: no`. `quiet` не включаем: на M0 сообщения Limine полезны.

**Про `·` в брендинге.** Символ U+00B7 есть в CP437 (0xFA), но если встроенный
шрифт Limine 12.9.6 его не отрисует — заменить на `-` (`AIOS - SkyNet v0.0.1`)
и записать это в отчёт T7; на сплэш это не влияет.

**Разрешение.** `interface_resolution` должен совпадать с разрешением,
которое запросит ядро в своём пункте (`resolution: 1280x800x32`), иначе при
передаче управления будет смена видеорежима и белая/чёрная вспышка. На
1920×1080-мониторе можно поставить `1920x1080` и в пункте ядра тоже
`1920x1080x32` — wallpaper тогда ляжет 1:1; сплэш останется фиксированного
размера (см. §4.3).

**Wallpaper кладётся в образ** (FAT-ESP) рядом с ядром, путь в конфиге —
`boot():/wallpaper.jpg`. В ядро JPEG не попадает.

## 11. Переход «меню → сплэш»

Задача — чтобы передача управления не выглядела как склейка двух картинок.
Что для этого делает дизайн:

1. **Один и тот же градиент.** Фон wallpaper собран из тех же трёх стопов
   (`#05070C` → `#0A1120` → `#04060A`); виньетка и свечение сдвигают его
   не больше чем на ±3 уровня. Когда ядро закрашивает экран построчно,
   верхняя часть кадра почти не меняется — нет вспышки и смены температуры.
2. **Один и тот же мотив.** Крупный «глаз» в меню — это та же апертура:
   разомкнутое кольцо с точкой-зрачком. Углы разрывов у колец разные (иначе
   система читается как мишень), но силуэт тот же; на сплэше он
   «схлопывается» в марку 64 px вверху по центру. Движения нет (анимация
   запрещена), но мотив узнаётся.
3. **Один и тот же акцент.** `#86A9FF` в меню (подсветка, таймер) и в марке —
   цвет не меняется.
4. **Один и тот же режим.** `interface_resolution` = разрешение ядра, поэтому
   Limine не переключает видеорежим на handoff.
5. **Порядок отрисовки.** Ядро начинает с `y = 0` и не очищает экран в чёрный
   перед градиентом: первая же строка совпадает с тем, что уже на экране.
6. **Никаких промежуточных кадров.** Между «Limine погасил меню» и «ядро
   нарисовало градиент» не должно быть текстовой консоли, курсора или
   очистки — только градиент и сразу марка.

Чего сознательно **нет**: анимации «глаз закрывается», кроссфейда и
подхвата wallpaper ядром (для этого нужен JPEG-декодер — запрещено на M0).
