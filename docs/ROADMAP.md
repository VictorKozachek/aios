# Дорожная карта версий

Формулировка владельца: «первая версия — это загрузка и возможность делать простые
промпты. Следующая — с RAG и мультимоделями. Потом подумаем про другие версии.»

## v0.1 — «загружается и отвечает»

Цель: доказать схему целиком, пусть и на минимальном уровне.

| Что | Как проверяется |
|---|---|
| Ядро грузится на реальном железе и в QEMU | UEFI → Limine → `_start` → карта памяти, ACPI, TSC |
| Консоль с моделью | `aios[work] >` → потоковый ответ локальной модели |
| Простые промпты | «кто ты», «объясни», «переведи» — без памяти |
| Воркспейсы | `home` и `work`: свои файлы, свои сессии |
| Сессии переживают перезапуск | лог сессии, продолжение диалога |

Граница версии: **модель не помнит ничего, кроме текущего лога**. Это осознанно —
сначала схема, потом память.

## v0.2 — «помнит и знает свои файлы»

| Что | Как проверяется |
|---|---|
| Долговременная память | факты с провенансом, `/remember`, `/memory`, `/forget` |
| RAG по файлам воркспейса | вопрос по документу → ответ со ссылкой на фрагмент |
| Мультимодели | выбор модели на воркспейс/сессию, переключение на ходу |
| Бюджет контекста | `/status` показывает состав: system / facts / tail / retrieved |

## v0.3+ — направления (обсуждаются)

- Перенос схемы в ядро: `modeld` со своим движком вместо ollama.
- Интерфейс: расширение консоли (в стиле харнесса), затем API.
- Память с KV-снапшотами (возврат к диалогу за секунды, а не минуты).
- Рабочие сценарии по воркспейсам: дом (досуг), работа (код, документы, дизайн).
- Наблюдаемость: стоимость токенов, время, аудит действий.

## Принципы перехода между версиями

1. Версия считается готовой, когда сценарий проверен на железе, а не только в QEMU.
2. Ничего не выкидываем: прототипные форматы (сегменты, факты) переносятся в ядро.
3. Каждая версия заканчивается тестовым дистрибутивом и релизом в `main`.

## Видимость репозитория

Решение владельца (2026-11-09): **репозиторий остаётся публичным до завершения v0.2**
(RAG + мультимодели), после чего переключается в приватный.

| Этап | Видимость | Причина |
|---|---|---|
| v0.1 (загрузка + промпты) | публичный | бесплатный CI, защита ветвей на Free, публичный след проекта |
| v0.2 (RAG + мультимодели) | публичный | показываем схему, пока она ещё не продукт |
| после v0.2 | **приватный** | появляется то, что жалко показывать: дистрибутив, ключи подписи, коммерческие планы |

Технические последствия переключения:

1. Приватный репозиторий на Free **теряет** защиту ветвей и обязательные ревью PR
   (это фичи Pro, $4/мес). Альтернатива — правила через Rulesets, они покрывают часть.
2. GitHub Actions на приватном репозитории тратят включённые вычислительные кредиты
   (Free: ~$12/мес), а не работают бесплатно без лимита, как на публичном.
3. Коллабораторы и права на пуш не меняются: пушить может только владелец, приватность
   влияет на видимость, а не на права.

Команда переключения: `gh repo edit VictorKozachek/aios --visibility private`
(обратно — `--visibility public`).
