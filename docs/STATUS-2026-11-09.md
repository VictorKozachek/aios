GitHub отклоняет пуш любой ветки, потому что в истории есть `.github/workflows/ci.yml`,
а у токена `gh` нет scope `workflow`:

```
refusing to allow an OAuth App to create or update workflow `.github/workflows/ci.yml` without `workflow` scope
```

Решение (одна команда владельца): `gh auth refresh -s workflow`, либо
`cd /Users/victor/projects/aios && git push origin v0.1`.
