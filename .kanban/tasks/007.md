## Задача

Сплэш при загрузке: `AIOS · SkyNet v0.0.1` на framebuffer (FR-9.5 спеки, PLAN-M0 T7).

**База ветки:** worktree создан от `task/T1-build` (там уже есть рабочий framebuffer-писатель
`kernel/src/console/fb.rs`, шрифт 8×8, и ядро доходит до `boot: ok`).

### Что нарисовать (spec v1 «Void», docs/design/splash-spec.md)

Реализуется утверждённый владельцем вариант v1; числа — из спеки,
импровизация запрещена, расхождения фиксируются в отчёте.

- фон: вертикальный 3-стопный градиент `05070C → 0A1120 → 04060A`,
  построчно, с 4×4 Bayer-дизерингом (§3);
- марка 64×64 (маска, `ACCENT` @242) — x = cx−32, y = top;
- wordmark 252×65 (маска, `INK`) — x = cx−126, y = top+102;
- `SkyNet v0.0.1` (атлас, `INK_DIM`, tracking +1) — baseline top+194, по центру;
- `git <hash>` (атлас, `INK_HASH`, tracking +1) — baseline top+218, по центру;
- линия-разделитель 480×1 (`WHITE` @23) — x = left, y = top+240;
- 4 строки статуса (baseline top+282+28i): точка `ACCENT`@178 (left+2, base−5),
  метка слева (left+16, `INK_DIM`), значение по правому краю (left+480, `INK`);
  значения — реальные из `BootInfo`: memory MiB, RSDP, cpus, tsc MHz;
- лог: атласом JBM15, x = left, первая baseline top+410, шаг 21 px, до H−48;
- геометрия (`spec §4`): `cx = W/2`, `left = cx−240`,
  `top = (H*42+50)/100 − 179`; ассеты фиксированного размера, на 800×600
  меняются только отступы.

Текст — только через атлас JetBrains Mono 15 (`spec §7`: ячейка 9×20,
16 колонок, ASCII 0x20..0x7E, baseline 15 px от верха ячейки), включая
строки лога в framebuffer-консоли. Старый шрифт 8×8 не используется.

### Версия

Решение владельца 2026-11-09: `AIOS_VERSION ?= v0.0.1` в Makefile
(переопределяется из env/CLI), `GIT_HASH = git rev-parse --short HEAD`;
ядро читает `option_env!`; fallback — `v0.0.0-unknown`. Критерий первой
редакции «версия совпадает с `git describe --tags --always`» снят: тегов
в репозитории нет, а заголовок карточки требует именно `v0.0.1`. Хеш на
скриншоте — HEAD на момент сборки (build-time).

### Ограничения

- Никаких искусственных задержек: время до готовности API не растёт.
- Serial и debugcon не ломать: `make smoke` (11 маркеров + debugcon) зелёный.
- Текст только атласом (§7), не 8×8.
- Границы T7 (расширены спекой v1 и решением владельца):
  `kernel/src/splash.rs`, `kernel/src/draw.rs` (примитивы отрисовки §1/§9),
  точка вызова `kernel/src/main.rs`, `kernel/src/console/{mod.rs,fb.rs}`
  (лог атласом §9; старый `console/font.rs` удалён), `kernel/src/assets.rs`
  (include сгенерированных масок §8), `kernel/assets/**`,
  `Makefile` (`AIOS_VERSION`/`GIT_HASH`/`WALLPAPER`),
  `build/limine.conf` (§10.1), `build/mkimage.sh` (wallpaper в ESP §10.1),
  `docs/assets/boot-splash.png` (приёмка). `serial.rs` и `boot/limine.rs`
  не трогать.

### Приёмка

- `make qemu` показывает сплэш v1 по §4/§7;
- `AIOS_VERSION` из сборки = `v0.0.1`, `git <hash>` отдельной строкой;
- скриншот снят через QEMU monitor и закоммичен в `docs/assets/boot-splash.png`;
- `make smoke` зелёный (11 маркеров + debugcon);
- читаемо на 1280×800 и 800×600 (координаты §4.1/§4.2);
- `make kernel AIOS_VERSION=` падает с понятной ошибкой (пустая версия).

### Как снять скриншот

```bash
cd worktrees/007
(make image >/dev/null)
qemu-system-x86_64 -M q35 -m 512 \
  -drive if=pflash,format=raw,readonly=on,file=/opt/homebrew/share/qemu/edk2-x86_64-code.fd \
  -drive file=build/aios.img,format=raw,if=ide -serial file:/tmp/s.log \
  -display none -no-reboot -monitor unix:/tmp/m.sock,server,nowait &
sleep 30
python3 -c "import socket,time; s=socket.socket(socket.AF_UNIX); s.connect('/tmp/m.sock'); time.sleep(0.5); s.recv(65536); s.sendall(b'screendump /tmp/splash.ppm\n'); time.sleep(2); s.sendall(b'quit\n')"
sips -s format png /tmp/splash.ppm --out docs/assets/boot-splash.png
```

PNG положить в `docs/assets/boot-splash.png` (создать каталог).
