## Задача

M1b: свой syscall ABI, загрузка ELF и первый процесс в userspace.
Зависимость: #016 (M1a: SMP + планировщик). Спека: ARCHITECTURE §2.2, §9.

### Что сделать

1. **Syscall ABI** (не POSIX): `SYSCALL/SYSRET`, точка входа, передача аргументов
   в регистрах, возврат кода ошибки; таблица вызовов: `region_create/map/share`,
   `chan_create/send/recv`, `time_now`, `log_record`, `obj_derive`.
2. **Загрузка ELF64**: парсинг заголовков, маппинг PT_LOAD с правами (W^X),
   отдельный стек пользователя, переход в ring3.
3. **Первый процесс**: минимальный сервис из `services/` (например `logd`), который
   печатает строку через syscall в консоль ядра. Никакой libc — свой рантайм.
4. **Обработка ошибок**: неверный указатель из userspace → возврат ошибки, а не паника ядра.
5. **Тест**: `AIOS_USER_TEST=1` — запустить процесс, получить его вывод, дождаться выхода.

### Приёмка

- в логе: `user: logd started (pid 1)`, строка от процесса, `user: exited code 0`;
- попытка исполнения из кучи → #PF с корректным дампом;
- `make smoke` 11/11; `cargo check` зелёный.

### Границы

`kernel/src/syscall/**`, `kernel/src/arch/x86_64/elf.rs`, `kernel/src/task/**`,
`services/logd/**`, `libs/no_std_rt/**`.
