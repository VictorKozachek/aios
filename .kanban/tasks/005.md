## Задача

Интегрировать `libs/mmcore` в ядро: реальная карта памяти, CR3, куча ядра, W^X.
Логика (buddy, структуры таблиц, арифметика) делается в #014 — здесь её не дублировать.

### Что сделать

1. По `BootInfo.memmap` построить набор кадров для buddy-аллокатора из `mmcore`.
2. Инициализировать таблицы страниц: HHDM (identity через смещение), MMIO — uncached,
   framebuffer — write-combined, куча ядра на выделенных страницах.
3. Включить NX и проверить W^X: исполнение из кучи → page fault.
4. Связать page-fault с обработчиком из T3 (#004) и журналом.

### Приёмка

В QEMU: `alloc 1 ГиБ` и освобождение проходят; попытка исполнения из heap даёт
page fault с записью в лог; `/metrics`-подобный счётчик памяти показывает занятое/свободное.

### Границы

`kernel/src/mm/**`, `kernel/src/main.rs` (только вызов инициализации).
`libs/mmcore/**` — чужая зона (#014).
