ротация 16 МиБ, checkpoint с `(segment_id, byte_offset)`, канонический CBOR за feature.

**Приёмка:** `cargo test -p memfmt` зелёный; тест «обрезка на каждом байте»;
порча середины → damaged; `cargo check --target x86_64-unknown-none` зелёный.
**Границы:** libs/memfmt/**.
