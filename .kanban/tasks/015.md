## Задача

Прототип «схемы»: поднять модель и дать человеку консоль, чтобы поиграть.
Полное описание — docs/PROTOTYPE.md (в основной ветке; прочитай его первым делом).

Цель этапа: `cargo run -p aios-console` → приглашение вида `aios[work] >`,
вопрос на русском → потоковый ответ модели, работа с воркспейсами `home`/`work`,
лог сессии. Память/RAG — следующим этапом (карточка 016), сейчас только каркас.

### Что сделать

1. **Отдельный Cargo-workspace** в `prototype/` (НЕ добавлять в корневой workspace:
   корневой собирается под `x86_64-unknown-none`, а прототип — std-крейты).
   `prototype/Cargo.toml` с members `modeld`, `console`.
2. **`prototype/modeld`** — адаптер модели:
   - trait `ModelBackend { info(); generate(req) -> stream; count_tokens(text) }`;
   - `OllamaBackend`: HTTP к `http://127.0.0.1:11434` (`/api/chat`, streaming NDJSON),
     модель из конфига (по умолчанию `qwen2.5:0.5b`);
   - аккуратные ошибки: сервер не запущен, модель не скачана — внятные сообщения,
     а не паника.
3. **`prototype/console`** — REPL:
   - приглашение `aios[<workspace>] >`, история команд в памяти процесса;
   - команды: `/ws home|work`, `/status`, `/new`, `/quit`, `/help`;
   - обычный ввод = сообщение модели; ответ печатается потоком (токен за токеном);
   - по Ctrl-D — корректный выход.
4. **Воркспейсы**: `~/.aios/workspaces/{home,work}/` — каталоги `files/`, `sessions/`,
   файл `config.toml` (модель, температура, системный промпт воркспейса). Создаются
   при первом запуске. Текущий воркспейс виден в приглашении.
5. **Лог сессии**: каждое сообщение и ответ дописываются в `sessions/<timestamp>.ndjson`
   (плоский JSON-лог; переход на memfmt — в 016). В `/status` показывать: модель,
   воркспейс, число сообщений, суммарные токены (из usage ollama), путь лога.
6. **Тесты**: юнит на парсинг стрима ollama (на фикстуре NDJSON, без сети) и на
   переключение воркспейсов (временный каталог через `HOME`).

### Приёмка

- `cargo run -p aios-console` (в prototype/) запускается, создаёт `~/.aios/workspaces/{home,work}`;
- ввод «привет, кто ты?» даёт потоковый ответ qwen2.5:0.5b;
- `/ws home` меняет приглашение и не даёт видеть файлы work (проверить командой, которая
  читает каталог; команды работы с файлами появятся позже, но проверка изоляции — тестом);
- `/status` показывает модель, воркспейс, токены, путь лога;
- перезапуск консоли сохраняет лог и позволяет продолжить;
- `cargo test` в prototype/ зелёный; корневой `cargo check --target x86_64-unknown-none` не сломан.

### Границы

`prototype/**` и отдельный `prototype/Cargo.toml`. Корневой Cargo.toml, kernel/, libs/ — не трогать.
Модель уже скачивается: `qwen2.5:0.5b`, сервер ollama слушает 127.0.0.1:11434.
